# 🧮 Calculator —— C 语言科学计算器

一个使用 **C11** 编写的命令行科学计算器。输入一条数学表达式，按回车即可得到结果。

## ✨ 功能

| 类别 | 支持内容 |
|------|----------|
| 基本运算 | `+` 加、`-` 减、`*` 乘、`/` 除 |
| 乘方 | `^`（右结合），也可用 `pow(a, b)` |
| 开根 | `sqrt(x)` |
| 对数 | `ln(x)` 自然对数、`log(x)` 以 10 为底、`log2(x)` 以 2 为底 |
| 阶乘 | `n!`（后缀写法，如 `5!`） |
| 三角函数（弧度制） | `sin(x)`、`cos(x)`、`tan(x)` |
| 三角函数（角度制） | `sind(x)`、`cosd(x)`、`tand(x)` |
| 其他函数 | `exp(x)`、`abs(x)` |
| 常量 | `pi`（或 `π`）、`e`，不区分大小写 |
| 其他 | 括号、一元正负号、小数、科学计数法 |

## 🛠️ 构建

### 方式一：直接使用 gcc / cc（最简单）

```bash
cd Calculator
make          # 编译，生成 bin/Calculator
make run      # 编译并启动
make test     # 编译并运行全部自动测试
make clean    # 清理编译产物
```

### 方式二：CMake

```bash
cd Calculator
mkdir -p build && cd build
cmake ..
cmake --build .
ctest            # 运行测试
../bin/Calculator
```

## 📖 使用方法

### 交互模式

```bash
./bin/Calculator
```

进入后逐行输入表达式，例如：

```text
> 2 + 3 * 4
= 14
> (2 + 3) * 4
= 20
> 2^10
= 1024
> sqrt(9) + 5!
= 123
> sin(pi/2)
= 1
> cosd(60)
= 0.5
> log(1000)
= 3
> quit
再见！
```

### 命令行直接计算

```bash
./bin/Calculator "2^10" "log(1000)" "5!"
```

## 📝 表达式书写规则

- **数字**：支持小数（`3.14`、`.5`）和科学计数法（`1e-3`）。
- **运算符优先级**（从高到低）：
  1. `!`（阶乘）
  2. `^`（乘方，右结合：`2^3^2 = 2^(3^2) = 512`）
  3. 一元 `+` / `-`
  4. `*` / `/`
  5. `+` / `-`
  - 括号可以改变优先级。
  - 按数学惯例：`-3^2 = -(3^2) = -9`；需要 `(-3)^2` 时请加括号。
- **函数**：函数名后必须跟括号，例如 `sin(pi/2)`、`sqrt(9)`、`pow(2,10)`。
- **常量**：直接写 `pi`、`π` 或 `e`。
- **暂不支持省略乘号**：请写 `2*pi`，不要写 `2pi`。
- **定义域检查**：
  - 除数不能为 `0`
  - `sqrt` 的输入不能为负数
  - `ln` / `log` / `log2` 的真数必须大于 `0`
  - 阶乘只接受 `0~170` 的非负整数
  - 负数底数的乘方只允许整数指数（如 `(-2)^2`）

## 📂 项目结构

```text
Calculator/
├── CMakeLists.txt          # CMake 构建脚本
├── Makefile                # make 构建脚本
├── README.md
├── include/
│   └── calculator.h        # 表达式求值核心 API
├── src/
│   ├── calculator.c        # 词法分析 + 递归下降语法分析 + 求值
│   └── main.c              # REPL 交互入口 / 命令行入口
└── tests/
    └── test_calculator.c   # 自动测试（覆盖全部基本功能）
```

### 维护者说明

- `calc_evaluate()` 是核心 API：输入表达式字符串，输出计算结果或带箭头定位的错误信息。
- 解析器采用**递归下降**方法，文法写在 `src/calculator.c` 文件头部。
- 新增函数时：
  1. 在 `unary_function()` 中增加定义域检查和 `math.h` 调用；
  2. 在 `tests/test_calculator.c` 中补充测试用例；
  3. 运行 `make test` 确认无误。
- 结果使用 `double` 存储，满足日常科学计算需求；需要任意精度时需引入额外大数库。

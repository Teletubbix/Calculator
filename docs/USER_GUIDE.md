# 🧮 Calculator v3.0.0 用户说明书

本说明书适用于 `main`、`linux`、`windows` 三个分支。

---

## 1. 这是什么

Calculator 是一个用 C 语言写的科学计算器，支持：

- 连续计算（不会算一次就退出）
- `Ans` 记忆上一次结果
- 设置显示小数位数
- 错误提示（除数为 0、负数开根等）
- Linux / Windows 图形界面

---

## 2. 快速开始

### 命令行版（main 分支）

```bash
git clone git@github.com:Teletubbix/Calculator.git
cd Calculator
git checkout main
make
./bin/Calculator
```

进入后直接输入表达式，按回车计算，按 `Esc` 退出。

示例：

```text
> 1 + 2 * 3
= 7
> (1 + 2) * 3
= 9
> 2^10
= 1024
> 5!
= 120
> e^2
= 7.38905609893065
> sin(Ans)
= 0.89385495491281
> precision 2
> 1/3
= 0.33
```

### Linux 图形版（linux 分支）

```bash
git checkout linux
sudo apt install libgtk-3-dev
make
make run
```

### Windows 图形版（windows 分支）

Windows 下运行 `build_windows.bat`，或使用 MinGW-w64 手动编译：

```bat
gcc -std=c11 -O2 -Wall -Wextra -Iinclude -municode -mwindows ^
    src\gui_windows.c src\calculator.c -o bin\Calculator.exe -lm
```

## 3. 运算符说明

| 符号 | 含义 | 示例 |
|------|------|------|
| `+` | 加 | `1+2` = 3 |
| `-` | 减 / 负号 | `5-3` = 2，`-3^2` = -9 |
| `*` | 乘 | `2*3` = 6 |
| `/` | 除 | `7/2` = 3.5 |
| `^` | 乘方（右结合） | `2^10` = 1024，`2^3^2` = 512 |
| `!` | 阶乘 | `5!` = 120 |
| `( )` | 括号 | `(1+2)*3` = 9 |

注意：暂时不支持省略乘号，请写 `2*pi`，不要写 `2pi`。

## 4. 函数说明

### 常用基础函数

| 写法 | 作用 | 示例 |
|------|------|------|
| `abs(x)` | 取绝对值 | `abs(-5)` = 5 |
| `sqrt(x)` | 开平方根 | `sqrt(9)` = 3 |
| `exp(x)` | 自然常数 e 的 x 次方 | `exp(1)` = e |
| `ln(x)` | 自然对数（底数 e） | `ln(e)` = 1 |
| `log(x)` | 常用对数（底数 10） | `log(1000)` = 3 |
| `log2(x)` | 以 2 为底的对数 | `log2(8)` = 3 |
| `pow(a, b)` | 计算 a 的 b 次方 | `pow(2, 10)` = 1024 |

### 三角函数

| 写法 | 角度单位 | 示例 |
|------|----------|------|
| `sin(x)` | 弧度 | `sin(pi/2)` = 1 |
| `cos(x)` | 弧度 | `cos(0)` = 1 |
| `tan(x)` | 弧度 | `tan(pi/4)` = 1 |
| `sind(x)` | 角度 | `sind(30)` = 0.5 |
| `cosd(x)` | 角度 | `cosd(60)` = 0.5 |
| `tand(x)` | 角度 | `tand(45)` = 1 |

## 5. 常量和 Ans

| 常量 | 含义 |
|------|------|
| `pi` 或 `π` | 圆周率，约 3.141592653589793 |
| `e` | 自然常数，约 2.718281828459045 |
| `Ans` | 上一次计算的结果 |

`Ans` 用法示例：

```text
> e^2
= 7.38905609893065
> sin(Ans)        # 相当于 sin(e^2)
= 0.89385495491281
```

## 6. 显示精度

命令行：

```text
> precision 2      # 之后的结果保留 2 位小数
> 1/3
= 0.33
> precision auto   # 恢复自动格式
```

图形界面：点击“精度”按钮，输入 0~15，或选择“自动”。

说明：精度只影响显示，`Ans` 内部保存完整精度，所以不会因为显示为 `0.33` 就按 `0.33` 继续计算。

## 7. 错误处理

以下情况都会给出明确提示，程序不会崩溃或退出：

| 输入 | 错误信息 |
|------|----------|
| `1/0` | 除数不能为 0 |
| `sqrt(-1)` | 负数没有实数平方根 |
| `ln(0)` | 真数必须大于 0 |
| `log(-10)` | 真数必须大于 0 |
| `1.5!` | 阶乘要求非负整数 |
| `(-2)^0.5` | 负数底数的乘方需要整数指数 |

本项目暂时不涉及虚数。

---

## 8. 优先级与常见问题

优先级从高到低：

1. `!` 阶乘
2. `^` 乘方（右结合）
3. 一元 `+` / `-`
4. `*` / `/`
5. `+` / `-`

注意数学惯例：

- `-3^2 = -(3^2) = -9`
- 要计算 `(-3)^2 = 9`，必须写括号

常见问题：

- 函数名后面必须带括号，如 `sin(pi/2)`。
- 不支持省略乘号，`2π` 应写成 `2*π` 或 `2*pi`。
- 表达式为空、括号不匹配、未知函数都会提示错误。

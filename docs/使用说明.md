# 📘 Calculator 使用说明（快速上手）

> 欢迎使用 **Calculator v6.0.6** —— 一款面向通信/理工科的科学计算器。
> 支持完整复数、相量极坐标、dB 功率换算、矩阵、单位换算，以及数值积分/求导/求根/求和/连乘。
> 本文带你在 5 分钟内上手。

---

## 一、怎么打开

### Windows（推荐绿色版）
1. 把 `Calculator-gui.exe` 连同同目录的 `lib*.dll`、`share/`、`lib/`、`assets/` 放在同一个文件夹（发行包已内置，无需安装 GTK）。
2. **双击 `Calculator-gui.exe`**（或用 `launch_gui.bat`）即可打开图形界面，**不会弹终端窗口**。
3. 想要命令行版，双击 `Calculator.exe`（会开一个命令行窗口，用于输入表达式/命令）。

### Linux
```bash
./Calculator             # 命令行版
./Calculator-gui-linux   # GTK4 图形界面（需已装 libgtk-4）
```

---

## 二、图形界面怎么用

- **输入表达式**：点顶部输入框，用屏幕按键或键盘输入，按 `Enter` 或点 `=` 计算。
- **结果显示**：显示在输入框下方；`Ans` 自动保存上一次结果，下一次可直接使用。
- **角度切换**：点 `DEG`/`RAD` 按钮切换角度制/弧度制（影响 `sin`、`cos`、`tan` 和相量 `∠`）。
- **显示格式**：
  - `a+bj` ↔ `R∠θ`：直角坐标 / 极坐标（相量）显示切换。
  - `标准` / `科学` / `工程`：记数法切换（工程法带 k/M/G、m/µ/n 词头）。
- **主题**：右下角按钮循环切换 7 套配色（蒙德 风、璃月 岩、稻妻 雷、须弥 草、枫丹 水、纳塔 火、至冬 冰）。
- **背景图**（可选）：把图片放到同目录 `themes/img/<主题>.png`，对应主题背景自动叠加图片，找不到就仍是纯渐变配色。

> 提示：想输入复数、相量、dB 等，直接按字母键或用函数键输入即可，例如 `3+4j`、`3∠30`、`dbm(10)`、`cabs(3,4)`。

## 三、命令行（REPL）常用示例

打开 `Calculator.exe` 或 `./Calculator` 后，逐行输入并回车：

```text
> 1/3                      = 0.333333333333333
> e^2                      = 7.38905609893065
> sin(Ans)                 = sin(e^2)
> (1+2j)*(3-4j)            = 11+2j          ← 复数乘法
> 3∠30                     = 2.59808+1.5i    ← 相量（当前角度制）
> cabs(3,4)                = 5               ← 复数的模
> dbm(10)                  = 10              ← 10 mW 已是 10 dBm
> convert 0 dBm mW         = 1 mW            ← 单位换算
> det2(1,2,3,4)            = -2              ← 2x2 行列式
> precision 2              ← 设 2 位小数
> 1/3                      = 0.33
> history                  ← 查看历史
> mode deg                 ← 切到角度制
> help                     ← 完整帮助
> quit                     ← 退出
```

### v6.0 数值工具（把表达式当函数 f(x)，用 `x` 作自变量）

```text
> integrate 0 1 x^2        = 0.333333333333333   ← ∫[0,1] x² dx
> nderiv 3 x^2             = 6                   ← (x²)' 在 x=3
> root 0 5 x^2-4           = 2                   ← 在 [0,5] 找 x²-4=0 的根
> sum 1 5 x^2              = 55                  ← 1²+2²+…+5²
> product 1 5 x            = 120                 ← 1×2×3×4×5
```

## 四、表达式书写要点

- 运算符：`+ - * / ^`；乘方用 `^`，也可 `pow(2,10)`；阶乘用 `!`（如 `5!`）。
- 函数名后**必须**带括号：`sin(pi/2)`、`sqrt(9)`、`atan2(y,x)`。
- 常量：`pi`(或`π`)、`e`、`tau`、`phi`、`Ans`；虚数单位 `j`/`i`；自变量 `x`。
- **不要省乘号**：写 `2*pi`，不要 `2pi`。
- 优先级：`!` > `^`（右结合）> 一元正负 > `* /` > `+ -`；`-3^2 = -9`，要 `(-3)^2` 请加括号。
- 复数：`3+4j`、`(1+1j)^2`、`exp(1j*pi)`、`sqrt(-1)=1i`。

## 五、常见问题（FAQ）

- **`2pi` 算不出来？** 不支持省略乘号，请写 `2*pi`。
- **算正弦结果不对？** 检查角度模式：`mode deg`（度）/ `mode rad`（弧度，默认）/ `mode grad`（百分度）。
- **如何得到复数/相量结果？** 默认就是复数引擎；输入 `3+4j` 或 `3∠30`，结果显示 `a+bj`；点 `R∠θ` 可切换为极坐标。
- **按钮白色看不清？** 已统一为近黑符号+浅色底，若仍有问题请反馈。
- **Windows 双击提示缺 DLL？** 请确认 `Calculator-gui.exe` 与所有 `lib*.dll`、`share/`、`lib/`、`assets/` 在**同一目录**（发行包已内置完整运行库）。
- **怎么换背景图？** 把图片放到同目录 `themes/img/<主题>.png`（文件名见下表）。

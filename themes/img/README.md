# 主题背景图（v6.0）

各原神主题的窗口背景可在纯渐变之上叠加**动漫背景图**。把图片文件放入本目录，
文件名为下表对应项，程序会优先加载（找不到则回退为纯渐变配色，不影响使用）。

| 主题          | 应放入的文件          |
|---------------|-----------------------|
| 原神·蒙德 风  | `mondstadt.png`       |
| 原神·璃月 岩  | `liyue.png`           |
| 原神·稻妻 雷  | `inazuma.png`         |
| 原神·须弥 草  | `sumeru.png`          |
| 原神·枫丹 水  | `fontaine.png`        |
| 原神·纳塔 火  | `natlan.png`          |
| 原神·至冬 冰  | `snezhnaya.png`       |

说明：
- 推荐尺寸：封面（cover）填充窗口，建议 ≥ 1200×1600 像素，PNG/JPG 均可。
- 图片按 `cover` 缩放并居中，始终填满窗口；按键、显示屏仍保持高对比前景色，
  不会出现“白色按钮+白色文字”的看不清问题。
- 文件也可放在可执行文件同级目录或 `themes/img/` 下（程序会依次查找）。
